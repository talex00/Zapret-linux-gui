# История изменений

## Не выпущено — первая Linux-версия

Перенос [Zapret-wrapper](https://github.com/talex00/Zapret-wrapper) с Windows (WPF, `winws.exe` + WinDivert)
на Linux (GTK4/libadwaita, `nfqws` + nftables).

### Сохранилось

- Прогрессивное раскрытие: блок появляется только когда для него есть данные.
- Простой и расширенный режимы, узкое окно без лишнего фона в простом.
- Автоподбор рабочей стратегии и журнал.
- Управление из трея, крестик не завершает обход.

### Изменилось по-сути

- Запуск обхода теперь две операции: правила NFQUEUE плюс демон `nfqws`.
- Права root берутся не на всё приложение, а только на привилегированный помощник через `pkexec`.
- Стратегии берутся из `config` (`NFQWS_OPT`), `strategies.txt` и встроенного набора,
  а не из `.bat`/`.cmd` пресетов.
- Трей необязателен: без AppIndicator крестик закрывает приложение.
